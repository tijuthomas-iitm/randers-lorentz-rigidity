# Code for "When do charged-particle trajectories determine their geometry?"

Authors: Faik Bouhrik and Tiju Thomas. This repository holds every script behind the computations in the paper
(Appendix A). Nothing here is needed to read the paper, but each computed claim can be reproduced from it.

## What the computations certify

| Paper statement | Script | What it certifies | Expected result |
|---|---|---|---|
| Theorem 2, generic rigidity (n = 3) | `generic_cert.py 3 3 gen 1` | exact rational ranks at one point | rank A = 659, rank B = 444, nullity(B) = 60, projected kernel = 1 |
| Theorem 2 (n = 2) | `generic_cert.py 2 3 gen 1` | same | 147, 85, 20, 1 |
| Vacuum certificates | `generic_cert.py 3 3 pwcirc 1`, `generic_cert.py 2 3 B 1` | same, at exact vacuum fields | as above |
| Independent reproduction | `k2_independent.py 3`, `k2_independent_2d.py 3` | separate implementation (sympy polynomials, Sarlet form of the Jacobi endomorphism, own random field and base velocity) | same ranks |
| Second multipliers accepted, controls rejected | `k1_k3.py` | known second multipliers solve the truncated system; wrong ones do not | 0 residual terms vs 72, 588, 542 for controls |
| Lemma 1 (w-block) | `k1_k3.py` | nullity n C(N+n, n) = 60 for generic and non-derogatory Jordan Phi0; 95 and 186 when derogatory | see `expected_output/` |
| Constant-kernel and central examples | `generic_cert.py` with modes `kerconst`, `pwlin`, `coulomb` | rank drops | rank A = 653, 653, 606 |
| Central-field identity | `central_lagr.py`, `central_lagr2.py`, `crofton_check.py`, `cp_check.py` | Euler-Lagrange expression of the added term vanishes on central dynamics | `expected_output/central_and_crofton_identities.txt` |
| Flag curvature is not gauge invariant | `flag_gauge_check.py` | K(\|y\|)=0, K(\|y\|+2k x1 y1)=3k^2 y1^4/F^4 on the Euclidean plane | `expected_output/flag_gauge_check.txt` |
| Identities in the worked derivations | `derivation_checks.py` | residuals all zero | `expected_output/derivation_checks.txt` |
| Reducibility evidence (numerical only) | `conjR_run.py`, `conjR_run2.py` | dimension of the algebra generated by Phi and its dynamical covariant derivatives | `expected_output/phi_algebra_reducibility.txt` |

All rank computations use exact rational arithmetic (python-flint `fmpq_mat`). Base velocities are Pythagorean so that
sqrt(1 - |v|^2) is rational. No floating point enters a certificate. The reducibility test (`conjR*.py`) is the only
floating-point computation, and is reported in the paper as numerical evidence only.

## Conventions

Signature (+,-,-,-), c = 1, charge-to-mass ratio 1, A_mu = (phi, -A), E = -grad phi - dA/dt, B = curl A
(Landau and Lifshitz). `helm_exact.py` builds the truncated Helmholtz system; `setup(n, N, seed, mode)` selects the field.
Field modes: `gen` (random potentials), `B`, `EB`, `static`, `pwlin`, `pwcirc`, `kerconst`, `kerconstE`, `radial`,
`radialshift`, `coulombish`, `coulomb`, `helical`, `axial`, `axialB`, `cyl`, `BzEz`, `Bperp`, `radial2`, `coulomb2`.

## Running

```
pip install -r requirements.txt
./run_all.sh
```

Full reproduction takes roughly an hour on one CPU core. Each script can be run on its own, from the `scripts` directory.
The recorded outputs are in `expected_output/`.

## Notes

- The certificates are at the truncation order N = 3. A run at N = 4 for n = 2 (`generic_cert.py 2 4 gen 1`) gives
  rank A = 347, rank B = 180, nullity 30 = 2 C(6,2), projected kernel 1.
- `phi_algebra_reducibility.txt` has 24 rows: the 23 field classes of the paper plus a 2+1 uniform electric field, whose
  rigidity has no independent record.
- `central_search2.py` records an unsuccessful earlier attempt (a second Lagrangian depending only on the energy and the
  angular momentum). It is kept because the paper mentions the negative result.
